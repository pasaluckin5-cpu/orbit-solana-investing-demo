# Orbit — мобильный инвестиционный интерфейс

Frontend MVP на React и Vite. Проект демонстрирует mobile-first интерфейс приложения для изучения токенизированных акций и ETF в экосистеме Solana.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Реализовано

- адаптивный интерфейс для мобильных и настольных экранов;
- поиск по каталогу демо-активов;
- переключатель периода графика;
- форма демо-покупки с расчётом количества долей;
- локальное обновление состояния портфеля после демо-покупки.
- подключение совместимых с Solana Wallet Standard кошельков;
- чтение публичного адреса и баланса SOL через Solana Mainnet RPC.

## Пока не подключено

Покупки, пополнение и вывод остаются демонстрационными: средства не двигаются, сделки не исполняются. Подключение кошелька только показывает публичный адрес и читает SOL баланс. На этом этапе приложение не просит подпись и не отправляет транзакции. Портфель и цены вымышлены.

Перед подключением реальных токенизированных акций требуется согласовать партнёрский доступ с эмитентом/поставщиком, определить законную модель для Казахстана и внедрить географические ограничения и KYC/AML там, где их потребует поставщик. xStocks указывает, что партнёры отвечают за географическое соответствие; текущая публичная информация не подтверждает право Orbit предлагать продукт в Казахстане. Токенизированные акции не равны владению обычными акциями: права определяются условиями эмитента.

Никогда не вводите seed-фразу или приватный ключ в Orbit, чат, `.env` или GitHub. Для собственного RPC можно задать `VITE_SOLANA_RPC_URL` (значение попадёт в клиентскую сборку, поэтому используйте только ключ, предназначенный для публичного браузерного приложения).
