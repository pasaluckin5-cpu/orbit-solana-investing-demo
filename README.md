# Orbit — мобильный инвестиционный интерфейс

Frontend MVP на React и Vite. Проект демонстрирует mobile-first интерфейс приложения для изучения токенизированных акций и ETF в экосистеме Solana.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Реализовано

- адаптивный интерфейс для мобильных и настольных экранов;
- поиск по каталогу демо-активов;
- переключатель периода графика;
- форма демо-покупки с расчётом количества долей;
- локальное обновление состояния портфеля после демо-покупки.

## Пока не подключено

Это frontend-прототип. Он не исполняет сделки и не подключает криптокошелёк, RPC, блокчейн-программу, хранение данных или поставщика ценных бумаг. Цены, портфель и история операций — демонстрационные данные. Перед реальными операциями нужно определить целевой регион, допустимую модель распространения токенизированных ценных бумаг и соответствующего лицензированного поставщика/кастодиана. Не вставляйте секретные ключи в браузерный код.
