## 🎯 Проблема
Молодые инвесторы и пользователи из регионов с ограниченным доступом сталкиваются с огромными барьерами при попытке инвестировать в мировые акции (Apple, Tesla, S&P 500):
* Сложная и долгая верификация (KYC) у традиционных брокеров.
* Высокие минимальные пороги входа и скрытые комиссии.
* Бюрократия и ограничения международных переводов.

## 💡 Решение (Orbit MVP)
**Orbit** — это быстрый *mobile-first* веб-сервис на Solana, который позволяет покупать токенизированные акции и ETF за пару кликов с помощью некастодиального кошелька (Phantom / Solflare). 

* **Мгновенный вход:** Подключение кошелька Solana за 1 секунду.
* **Прозрачный рынок:** Каталог токенизированных активов с актуальными котировками.
* **Ончейн-расчёты:** Все операции фиксируются в сети Solana с минимальными комиссиями.

---

## 🛠 Архитектура и Технологии
Проект построен на современном стеке для экосистемы Solana:
* **Frontend:** React, Vite, Tailwind CSS (для быстрого и адаптивного UI).
* **Web3 Integration:** Solana Web3.js / Wallet Provider API (взаимодействие с Phantom и Solflare).
* **Network:** Solana Mainnet / Devnet (высокая скорость транзакций, низкие издержки).
